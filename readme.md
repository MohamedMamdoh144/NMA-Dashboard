# Interactive Dashboard for MS Disease Modifying Therapies (NMA)

This dashboard accompanies the manuscript **"[Title]"** published in [the].

## Overview
It visualizes the results of a Network Meta-Analysis (NMA) comparing the Efficacy and Safety of DMDs for Multiple Sclerosis.

## Features
- **Benefit-Risk Assessment:** Multi-Criteria Decision Analysis (MCDA) weighting.
- **Detailed Profiles:** Radar charts for individual efficacy/safety outcomes.
- **Head-to-Head Analysis:** Forest plots for specific drug-to-drug comparisons.

## Data Source
Data is derived from the systematic review and NMA conducted by [Authors].

## How to Run Locally
1. `pip install -r requirements.txt`
2. `streamlit run dash.py`
